# Tainers

This repo is just a collection of Dockerfiles for lightweight containers.  
Feel free to contribute your own Dockerfiles for other languages and tools.

## Structure

Make a folder for your project or for your user.  
Example:
```
hackflare/
```

Then add your Dockerfiles in that folder.  
Example:
```hackflare/
├── dockerfile
├── builder/
│   └── dockerfile
```
